# UI for the Amberbase example backend

## Setup

> [!IMPORTANT]
> The build command below only works, if the `amber-client` package is available (see package.json). Therefore the
> amberbase client must be available at '../../amberbase/src/client'.

```sh
cd ../.. # Go to the parent folder of the current project
git clone https://github.com/amberbase/amberbase
cd amberbase/src/client
npm install
npm run build
```

Now install dependencies, compile and copy built files into the backend folder:

```sh
npm install
npm run build
```
